# Juno Beach images: sources

Photos are **copied** from John Oliver's own photo library (`Website Folders/Doyouneedphotos/Juno Beach/`, 27 photos and
1 video; nothing there was moved, renamed or changed). The library copies carry no EXIF data, so location rests on what
is visible in each frame and on John's confirmation. The page credit reads "Photo by John Oliver". Derivatives are WebP
(q80): heroes 2048×1152 with a 1200×800 phone crop, in-article images 1400×1050, embedded with explicit dimensions.

The older numbered files in this folder (`juno-beach-0xx.jpg`/`.jpeg`) have no recorded origin. `juno-beach-022.*` is North Palm Beach (per John, 2026-10-01) and `juno-beach-037.*` (rope-rail boardwalk) matches nothing in the library, so neither is used on rebuilt Juno Beach pages. `juno-beach-002.jpg` is an edited copy of the Pelican Lake gazebo frame (`IMG_8948`), `juno-beach-005.jpg` is `IMG_1414` (the pier) and `juno-beach-025.*` is `IMG_8948` (the Pelican Lake gazebo) and `juno-beach-085.*` is `IMG_8947` and `juno-beach-027.*` is a frame from the same Town Center sign set (both with a private residence in frame). `juno-beach-070.*` is the Jupiter Inlet Lighthouse in Jupiter, and `juno-beach-026.*` is a Singer Island view from Tiara. Other Juno Beach
articles and the community page still use them.
